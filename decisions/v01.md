# v01: fixed-order screening, paired-bootstrap shortlist, tuning of the shortlist

Status: analysed. Designed, built and run 2026-11-02. Git tag `v01` (commit `2e19c8e`).
Config: `conf/agent.yaml`. Outputs: `artifacts/versions/v01/seed_0/agent/` (copied from the
dry run in `artifacts/dryrun/seed_0/agent/`). Models: U (UNI2-h), V (Virchow2), plus age and
sex. Full specification: [`../docs/agent.md`](../docs/agent.md).

## 1. Motivation

First version of TASK.md Step 2: a structured agent that searches how to combine the
foundation-model slide vectors with age and sex, under a fixed budget, with every decision
logged and guarded against overfitting the 162 development patients.

## 2. Design

- **Search space, 11 recipes, every one using all blocks (U, V, M = age and sex):**
  - *Early* E1–E4: blocks joined, each block standardised and block-scaled to equal total
    variance; {no L2, row L2} × {no PCA, PCA k}; one class-weighted multinomial logistic
    regression (LR).
  - *Late* L1–L4: one LR per block (M has its own LR on [age, sex]); combined by probability
    average (L1), log-probability average (L2), weighted vote with weights inner-CV AUROC
    − 0.5 (L3), stacking LR on inner out-of-fold log-probabilities (L4).
  - *Learned* N1–N3: each block standardised and projected `Linear(p_b → d) → GELU →
    Dropout(0.25)`; M by `Linear(2 → d)`; mixed by a softmax gate (N1), 2-head
    self-attention over streams (N2), low-rank bilinear `(A·h_img) ⊙ (B·h_M)` (N3); linear
    softmax head; AdamW, 100 epochs, 3 seeds averaged.
- **Phase 1:** all 11 once, fixed order, fixed values (C 0.01 for image/joint LR, C 1 for
  the age-and-sex LR and the stacker, weight decay 0.01, size 32).
- **Shortlist:** best Phase 1 recipe plus every recipe it does not beat in ≥ 90% of 2,000
  paired, class-stratified bootstrap resamples; at most 3.
- **Phase 2:** shortlisted recipes with C or weight decay chosen by inner 5-fold CV over
  {0.0001, …, 1}; size 32 → 64 → 16 (16 only if 64 was not better).
- **Final selection:** the candidate (highest AUROC) wins only if it clearly beats every
  simpler shortlisted recipe (wins ≥ 90% of resamples, balanced accuracy ≤ 0.02 lower);
  otherwise the simplest not clearly beaten recipe wins.
- **Budget** 20 experiments; 30-min cap per experiment. Experiment = 8-fold development CV.

## 6. Analysis: why v01 did not beat row 5

1. **Little complementary signal between the two image models.** Their errors largely
   coincide (both wrong for 47.5% of patients; each alone 51–56%), so combining them can
   correct only a few patients. The best fusion gains over row 5 were +0.007 to +0.017,
   inside CIs of about ±0.03.
2. **Age and sex added nothing measurable.** Row 5b (the winner's age-and-sex handling on
   UNI2-h alone) equals row 5 (−0.001 [−0.014, +0.011]). In v01 age enters linearly only
   (or through one joint 2 → 32 projection), so a non-linear age effect (In situ patients
   are about 10 years younger) cannot be expressed by the linear recipes.
3. **Tuning hurt the selected recipe.** L2 dropped from 0.808 (fixed values) to 0.797
   (tuned): each base model's C is chosen for its own AUROC on ~113 patients, which is
   noisy and not the objective of the combination.
4. **The selection rule rejected the best AUROC.** Tuned L4 had the highest AUROC (0.816)
   but balanced accuracy 0.381: the stacker improves ranking (AUROC) but its arg-max class
   decisions are poor at n = 142.
5. **Too little search, all of it blind.** The fixed-order screen spent 11 of 13
   experiments without reacting to any result; only two recipes were ever tuned; the
   learned recipes were never tuned; 7 experiments of budget were left unused.
6. **Fixed Phase 1 values misfit some recipes.** E3/E4 with C = 0.01 lost ~0.05 AUROC
   (separately timed tuned E3: C 0.1–1, AUROC 0.764).
7. **Resolution limit.** With 162 patients, per-experiment CIs are about ±0.04; a true
   fusion gain of +0.01 cannot pass a 90% paired rule reliably. Row 5 is itself slightly
   optimistic (its model is picked on the same scores).

## 7. Step back (first principles)

- **Bottleneck:** mainly *search* and *representation of age and sex*, secondarily
  *signal* (two similar models). Variance and selection noise set the floor of what can be
  shown.
- **Assumptions that may be wrong:** that a fixed sweep is enough exploration; that a
  linear or single joint projection is the right encoding of age and sex; that tuning each
  base model separately helps the combination.
- **Directions:** (a) an adaptive loop that spends the budget where the evidence points;
  (b) learned and non-linear encodings of age and sex (feature tokenizers, periodic and
  piecewise-linear embeddings; Gorishniy et al. 2021, 2022); (c) fair, matched baselines
  (every single-model row computed with the winner's recipe and tuning), so the fusion
  effect is isolated (TASK.md line 162).

## 8. Proposal for v02

All three, as one version: the adaptive loop (fixes Problem 1), an age-and-sex tokenizer
axis searched by the agent, all tuning by inner CV with matched baselines (fixes Problem 2).
Budget unchanged (20). Specified in [`v02.md`](v02.md).
